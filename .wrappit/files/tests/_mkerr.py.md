# tests/_mkerr.py

## What it is
A one-off generator script that writes the first twelve compile-error tests (e01 to e12) into tests/err/, each with an `; err:` header naming the expected diagnostic.

## How to navigate it
The `cases` dict maps a file name to a pair of (expected error substring, VIBE source); the loop at the bottom writes each file and prints how many it wrote.

## What it interacts with
Writes tests/err/e01_mixed_ops.vibe through tests/err/e12_break_outside.vibe, which tests/run.py later checks with `run_err()`. It imports only the Python standard library.

## Why it exists
It bootstrapped the negative tests that prove the compiler rejects things VIBE forbids, like mixed operators without brackets, non-exhaustive matches and silent width mixing.

## Helpful notes
Running `python3 tests/_mkerr.py` overwrites those twelve files. tests/err/ now holds e01 to e24; e13 onward are not generated by this script.
