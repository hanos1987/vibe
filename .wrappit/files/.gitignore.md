# .gitignore

## What it is
Git's list of paths to keep out of version control for the VIBE repo.

## How to navigate it
Eight lines: packaging output (`packaging/out/`, `packaging/apt/`), Python build leftovers (`build/`, `*.egg-info/`, `__pycache__/`, `*.pyc`), compiled `*.bin` files, and the generated `bench/*.c` files.

## What it interacts with
- git.
- Output folders written by packaging/release.sh, packaging/mkdeb.sh and packaging/mkrepo.sh.
- C files that bench/run.py writes into bench/.

## Why it exists
Keeps build artifacts, release files and the generated APT repository out of commits.

## Helpful notes
`packaging/apt/` (the built APT repo, including the exported public key) is ignored, so it must be synced to benjiapps.com by hand; it is never in git.
